# Session S59 — 2026-07-04
**Topic:** infrastructure

## The Problem
Claude could not edit files on Google Drive. The Drive connector can read, search, and create — but not edit. Every "edit" produced a new file, so working documents kept multiplying into duplicates. GitHub worked as a workaround for text files, but it lives outside Chris's daily tools — a hassle for anything that isn't code or markdown.

## Questions We Were Trying to Solve
- How can Chris and Claude both edit and share the same working files easily?
- Is there a Google-native way to do it, since Chris already lives in the Google ecosystem?
- Why wasn't Google Drive for Desktop syncing even though it appeared installed?

## What We Tried That Didn't Work
- Editing through the Drive connector directly — no edit capability exists, period.
- Connecting ~/Documents/Claude — blocked (Cowork reserves that folder for its own scheduled-task files).
- Folder-name guessing and the folder picker — "Claude GDrive" existed only in Drive's stale web view, never on the Mac.
- Drive for Desktop initially crashed on launch with a macOS File Provider error.

## What We Built
**The breakthrough: a synced local folder as the shared editing workspace.** Created `~/Documents/G Drive with Claude` on the Mac, connected it to Cowork, and got Drive for Desktop running again (the File Provider crash was fixed by restarting the Mac). Claude now edits files locally with full read/write, and Drive for Desktop syncs every change to the cloud automatically — visible on any device under Computers > My MacBook Pro > Documents. The rule was made permanent in CLAUDE-CORE.md (V8): all working documents go through this folder. No more duplicates, no more read-only wall.

## Key Decisions
- All working documents flow through `~/Documents/G Drive with Claude` — the only editing method (CLAUDE-CORE V8, changelogged).
- Regular file formats only (.md, .docx, .xlsx, .pdf) — native Google Docs/Sheets can't be edited this way.
- GitHub stays the system of record for soul files; the synced folder is for working docs.
- **YouTube content note:** this belongs in an early setup episode of the channel — "use Google Drive for Desktop as your Claude workflow." Before this, Claude kept creating duplicate files on Drive. GitHub is a workaround, but if it's not in your regularly used products it's a hassle. If you're already in the Google realm, this is the way to go.

## What's Alive Now
- Google Drive for Desktop running and syncing on the MacBook Pro.
- `~/Documents/G Drive with Claude` — shared working folder, Cowork-connectable, auto-syncing both directions.
- CLAUDE-CORE.md V8 with the mandatory WORKING DOCUMENTS section.

## What's Next
