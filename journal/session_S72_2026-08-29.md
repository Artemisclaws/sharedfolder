This session started as a narrow task (patch CLAUDE-CORE.md's FILE SYSTEM REFERENCE section to reflect two folders created in a prior session) but Chris interrupted mid-patch to name the real problem directly: folder reshuffles alone haven't fixed it before, so this time the structure needed to be reasoned out properly, once, before touching anything else.

## What We Built
A locked design doc (`checkpoint_gdrive-folder-system-design_2026-08-29-v2.md`) superseding the 2026-08-06 design's account/folder model, grounded in three named proven models per CLAUDE-CORE's own Proven-Model Standard: Tiago Forte's PARA method (the Atlas/Active/Final/Resource/_ARCHIVE bucket shape), Gino Wickman's EOS scorecard/rocks/issues (shapes "The Bridge," the Cowork Artifact dashboard Chris built separately), and Gmail's founding "search, don't sort" design principle (justifies live search over a hand-maintained file map). Locked: a 3-account role split (chrispinyo = bulk storage minus Aura Thai; aurathailb = dedicated Aura Thai home; artemisclaws = AI-operational, folder-scoped access only, never a whole account); the 5-bucket top-level shape with per-business subfolders; JOURNAL staying single-homed on GitHub as an ongoing record widened to include life/personal topics, since Chris wants the whole journey — business, life, AI — recorded, potentially for a future YouTube channel; the Mac "G Drive with Claude" folder's real purpose named for the first time as Claude's editable Active/ mirror, fixing the actual root cause of "Claude keeps creating new files instead of editing"; a GitHub-freshness fix for The Bridge (mirror a status snapshot to Drive at every handoff, since the artifact can't safely hold a GitHub PAT and currently needs manual per-session resync — verified 14+ days stale this session); and a file-naming convention distinguishing living files (versioned) from point-in-time files (ISO-8601-dated).

## Key Decisions
- 3-account role split confirmed by Chris: chrispinyo = bulk minus Aura Thai, aurathailb = dedicated Aura Thai home (everything Aura-Thai-related consolidates there, with a dedup pass before any deletion), artemisclaws = AI-operational with folder-scoped Editor access only.
- 5-bucket top-level shape (ATLAS/Active/Final/Resource/_ARCHIVE) wins over the prior session's per-business nesting.
- No hand-maintained file map, by design — live cross-account search plus a small pinned-links registry on The Bridge, validated against Gmail's "search, don't sort" precedent and Forte's "just-in-time organizing" before locking it in.
- Connector approach: share aurathailb's target folders as Editor with artemisclaws, reusing the existing Drive MCP connector, rather than adding a second one.
