# Session S63 — 2026-07-08
**Topic:** aura-thai

## The Problem
A-11 PATH-TO-BLACK had been redirected four straight sessions (S58/S60/S61/S62) while Aura Thai runs YTD −7.5%. Nobody knew the true break-even. And the cost side of the business — payroll, rent, utilities, the cash/reported split for the chefs — lived only in Chris's head, re-dictated every time it came up.

## Questions We Were Trying to Solve
- What does it actually cost to run Aura Thai for a month, bare minimum?
- How much tax does the restaurant absorb for the flat-rate chefs, and what is their true hourly pay?
- Where should this data live so Chris never has to dictate it again — and so every session can find it?
- Why did earlier sessions "lose" financial data Chris had already given?

## What We Tried That Didn't Work
- The session itself booted off a then-current S58 SPRINT and stayed open while S59–S62 happened elsewhere — early deliverables carried a wrong session number and date, and the handoff nearly ran on a stale V7 protocol. The V9 freshness gate (re-run before writing) caught it.
- First storage pass (GitHub only) was correct per old core docs but invisible to Chris (can't access GitHub) and unregistered — exactly how data gets "lost." Fixed by the Bedrock pattern: REGISTRY entry + SPRINT pointer + a sheet tab Chris can open.

## What We Built
Complete cost-side ground truth for A-11, captured on payday: all 12 people (BOH flat-rate chefs with the net-check + cash structure, FOH W-2 staff, Chris's own sometimes-undeposited salary) and every known fixed cost. The tax-absorption question got a real answer: ~$361 per pay period, ~$782/mo, ~$9.4K/yr absorbed for the three reported chefs. Everything landed in `aura-thai/COST_BASELINE.md` (canonical, GitHub) plus an Apps Script (`cost_baseline_tab_builder.gs`) that builds a "Cost Baseline" tab with a live break-even calculator inside aura_thai_finance — numbers in the sheet Chris owns, memory in the repo agents read. Known costs: ~$44.9K/mo before COGS. At a 30% COGS scenario, break-even is ~$2,110/day against May's ~$2,200/day — the restaurant is skating at the line before water, insurance, and card fees are even counted.

## Key Decisions
- Numbers live in ONE master sheet (aura_thai_finance, new tab) per the Dashboard Architecture Rule; GitHub remains the agents' brain. Chris never needs GitHub access.
- Apps Script tab-builder over any second document — Chris chose the single-master-sheet option explicitly.
- Chris's undeposited paychecks are modeled as real cost, not savings.
- Chef hourly-rate/minimum-wage exposure added to the INV-15 tax-preparer question list.
- Session counter reconciled: this chat = S63; long-lived chats must re-run the boot gate before handoff writes.
