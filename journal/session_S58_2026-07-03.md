Chris connected an external HD (Crucial 2TB) to consolidate and organize RoamWithChris footage — RWC-06 and RWC-05 (Story Index) had been sitting open/blocked since S54. Chris had also run into files that "won't open" after he'd manually renamed some raw 360 clips, without knowing why.

## What We Tried That Didn't Work
- First inventory pass treated a folder named "Havasupai, Japan, Thailand,  2025" as three merged trips needing to be split by date. Wrong — investigation showed it held zero master footage, only orphaned proxy files (.lrv/.bmp) whose real masters already lived correctly filed elsewhere. Caught before acting on the wrong theory.
- An early dry-run matching script reported 0 matches for those proxies due to a path-filter bug (excluding every subfolder because of a `.` in the relative path). Caught by sanity-checking the result before trusting it, fixed, rerun — got 429/506 real matches.

## What We Built
Cleaned the drive (2,055 junk files gone), reorganized 429 orphaned proxy files back to their real trip folders, restored 6 renamed/collision-damaged files to playable Insta360 pairs, and audited the entire drive for broken pairs (found 32 genuinely unrecoverable — cross-checked, not guessed). Diagnosed the actual root cause of Chris's "renamed files won't open" complaint: manually renaming raw `.insv` files destroys the 00/10 lens-pair signature Insta360 software needs to reconstruct the sphere. Locked a permanent policy — raw camera-original files never get renamed again; framing happens in Insta360 Studio, and only the exported flat clip (going to "Edited Shots") gets a descriptive name. Built a 3,505-row Footage Manifest (Phase 1 of the long-blocked Story Index) as the real, mechanical foundation the story/theme layer gets built on top of later.

## Key Decisions
- Investigate before acting on a folder name's implied story — the "3 merged trips" theory was wrong and would have caused a bad split.
- Don't guess file pairings when the ID signature is gone (Vegas/Mammoth renamed files) — flagged for manual review instead.
- Build the manifest (mechanical layer) now, not the full Story Index — narrative fields need Chris, not automation.
